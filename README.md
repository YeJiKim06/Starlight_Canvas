우주 공간에 나만의 아이디어 별자리를 수놓는 아기자기한 브레인스토밍 플랫폼 기획서입니다. 구현 가능성과 귀여운 UX 감성을 모두 잡을 수 있도록 구성했습니다.

# 📄 [기획서] 별빛캔버스 (Starlight Canvas)

> **"생각을 쏘아 올려 나만의 아이디어 별자리를 만드는 아기자기한 브레인스토밍 공간"**

---

## 1. 서비스 개요

* **서비스명**: 별빛캔버스 (Starlight Canvas)
* **컨셉**: 밤하늘이라는 무한한 공간 위에 생각(별)을 하나씩 띄우고, 생각들을 이어 자신만의 아이디어 별자리를 완성하는 감성 브레인스토밍 도구
* **주요 타겟**:
* 딱딱하고 무거운 회의 도구에 피로감을 느끼는 기획자 및 개발자
* 아기자기한 디자인으로 자유롭게 창의력을 발휘하고 싶은 아이디어 스케치 사용자


* **핵심 가치**: 직관적인 작동 방식, 시각적·음향적 즐거움, 부담 없는 실시간 협업

---

## 2. 디자인 & 비주얼 가이드

* **메인 컬러 팔레트**:
* 배경: 파스텔 딥 딥퍼플/네이비 (`#1C1B29` ~ `#2B2942`) — 너무 어둡지 않고 포근한 밤하늘 느낌
* 아이디어 노드(별): 버터 옐로우, 파스텔 핑크, 민트 블루, 솜사탕 퍼플


* **비주얼 스타일**:
* 완벽한 직각/직선 대신 약간 몽글몽글하고 둥근 테두리와 손그림 질감 사용
* 노드 생성, 연결, 클릭 시 통통 튀는 애니메이션(Spring Effect) 및 은은한 별빛 입자 효과(Particle Effect) 적용



---

## 3. 주요 기능 요구사항

### 3.1 무한 우주 캔버스 (Infinite Canvas)

* 캔버스를 드래그하여 이동하고, 마우스 휠로 확대/축소가 가능합니다.
* 배경에는 아주 작고 잔잔하게 반짝이는 별 배경 효과가 깔려 있어 밤하늘을 떠다니는 느낌을 줍니다.

### 3.2 별 아이디어 노드 (Idea Star)

* **아이디어 카드 작성**:
* 캔버스 빈 곳을 더블 클릭하면 몽글몽글한 별/행성 모양의 노드가 생성됩니다.
* 텍스트를 입력하면 별 카드 크기가 글로 적당히 조절됩니다.


* **별자리 연결 (Node Linking)**:
* 별 노드의 테두리를 끌어 다른 별로 드래그하면, 두 별이 '점선 별자리 라인'으로 이어집니다.
* 연관된 아이디어들이 모여 하나의 별자리 형태를 이룹니다.



### 3.3 별똥별 캡슐 기계 (Idea Spark)

* **위치**: 화면 우측 하단에 배치된 귀여운 장난감 뽑기 기계 아이콘
* **작동**: 생각이 막혔을 때 레버를 당기거나 버튼을 누르면, 화면 상단에서 별똥별이 슝 떨어지며 캡슐이 터집니다.
* **제시어 카드 예시**:
* "이 아이디어를 7살 어린이에게 설명한다면?"
* "예산을 10배로 늘린다면 어떤 기능을 넣을까?"
* "반대로 완전히 실패하게 만들려면 어떻게 해야 할까?"



### 3.4 우주유영 마우스 커서 (실시간 멀티유저)

* 실시간으로 함께 접속한 팀원들의 커서가 **작은 외계인, 우주비행사, 별똥별, 유령** 아이콘으로 표시됩니다.
* 커서를 빠르게 움직이면 커서 뒤로 살짝 반짝이는 별가루 잔상이 남습니다.
* 커서끼리 가까이 다가가 부딪히면 뿅! 소리와 함께 작은 하트나 별이 팝콘처럼 터집니다.

### 3.5 별도장 반응 (Reaction Stamp)

* 다른 사람이 낸 아이디어 별 노드 위에 칭찬 스티커 형태의 도장을 찍을 수 있습니다.
* **도장 종류**: 반짝이 별, 슈퍼스타, 칭찬 도장, 질문표 구름 등
* 도장을 찍으면 해당 별 노드가 순간적으로 환하게 빛나며 통통 튑니다.

## 5. 기술 구조 및 구현 방안 (개발 가이드)

개발 프레임워크와 기술 스택은 프론트엔드와 실시간 서버 통신에 초점을 맞추어 선택할 수 있습니다.

### 5.1 프론트엔드 (Frontend)

* **캔버스 렌더링 엔진**:
* **React-Flow** 또는 **Konva.js (React-Konva)** 활용 추천
* *이유*: 캔버스 위에서 노드 드래그앤드롭, 노드 간 선 연결, Zoom/Pan 기능 및 커스텀 노드 스타일링(별 모양, 애니메이션)을 가장 손쉽게 구현할 수 있습니다.


* **스타일링**:
* **Styled-Components** 또는 **CSS Modules / SCSS** 활용
* 별빛 입자 및 몽글몽글한 Spring 애니메이션 처리를 위해 `framer-motion` 라이브러리를 함께 사용하면 수준 높은 애니메이션을 손쉽게 구현할 수 있습니다.



### 5.2 백엔드 & 실시간 동기화 (Backend)

* **실시간 협업 서버**:
* **Node.js (Socket.io)** 또는 **Yjs (CRDT 기반 라이브러리)**
* *이유*: 여러 유저의 마우스 커서 위치, 노드의 좌표 이동, 스티커 반응을 지연 없이 실시간으로 방송(Broadcast)해 주는 데 최적입니다.


* **데이터 저장**:
* 보드 단위의 노드 구조(JSON 형식)를 저장하기 위해 **MongoDB** 또는 **PostgreSQL** 활용

## 6. 단계별 개발 로드맵

1. **1단계 (MVP - 최소 기능 제품)**
* 무한 캔버스 기본 조작 (이동, 확대/축소)
* 기본 별 노드 생성, 텍스트 입력, 노드 간 점선 연결 기능
* CSS 애니메이션을 이용한 기본 파스텔 밤하늘 테마 구현


2. **2단계 (협업 & 귀여운 요소 추가)**
* Socket.io를 활용한 실시간 커서 공유 및 별 노드 위치 실시간 동기화
* 캐릭터 마우스 커서 및 잔상 이펙트 적용
* 별도장 반응(스탬프) 기능 추가


3. **3단계 (재미 요소 강화)**
* 우측 하단 '별똥별 캡슐 뽑기' 랜딩 인터랙션 및 프롬프트 카드 팝업
* 사운드 효과음(노드 생성 소리, 도장 찍는 소리 등) 적용
